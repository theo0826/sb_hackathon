# 한땀 디자인 유지 기준

기존 `.taste-skill/direction.json`의 방향 `borrowed-category`, seed `1864123466`을 유지한다. 새 방향을 추첨하지 않는다.

- 현재 기준 화면: 2026-11-02의 온보딩, 디자인 스튜디오, 주문서, 업체 견적, 마이페이지.
- 색상: 회색 `#f1f3f6`, 남색 `#041e41`, 본문 `#191f28`, 연두 `#b3d214`.
- 기존 레이아웃, 폰트, 반응형 배치, GSAP 온보딩, 버튼 피드백을 유지한다.
- 기존 앱 UI의 그림자·테두리·보조 글자는 승인된 디자인의 일부다. 마케팅 페이지 규칙에 맞추려고 변경하지 않는다.
- 런타임 로고·아이콘은 `public/ui/`, 온보딩 원본은 `public/onboarding/`, 폰트와 라이선스는 `app/fonts/` 및 `public/fonts/`에 있다.
- 사용 중인 SVG는 디자인 원본 파일이 아닌 화면 실행 자산이다. 삭제 전 실제 참조를 확인한다.
- 디자인 수정 시 `design-taste-frontend`를 읽고 실제 브라우저 PC·모바일에서 확인한다.
- 시연 전 기능·디자인을 임의로 추가하지 않는다. ClothSim 코드는 백엔드팀이 관리한다.

2026-11-02 정리 작업에서는 화면 스타일을 변경하지 않고, 사용 중인 SVG 경로만 `/figma/`에서 `/ui/`로 옮겼다.
