# 전체 의상 요청 연결 준비: 검증 기록

## 범위

프론트가 의류·색·원단·소매·테두리와 앞뒤 여러 이미지/문구 배치를 구조화된 결과로 받아 표시하는 프로토타입이다. 실제 자유 문장 해석과 생성 이미지 품질, 계정/요금 운영은 백엔드 팀원의 인수 범위다. 검증 중 `OPENAI_ENABLED=false`를 유지했고 실제 유료 AI를 호출하지 않았다.

## 통과한 검사

- `npm run test:unit`: 공통 JSON fixture/기존 자료 호환, 문구 이스케이프, 원본 재사용, 단일 배치 54조합, 다중 배치 9조합의 좌표 역변환, 세 의류의 앞뒤 모든 데칼 표면, 리소스 해제, 가짜 AI 응답 처리.
- 실제 Supabase 연동 검사: 디자인·원단·미리보기의 비공개 저장, 여러 배치 보존, 다른 소유자의 조회/자산 재사용 거부, 업체 3종의 목업 변환, 중복 요청, 유료 AI 작업 예약 0건, 브라우저 번들·페이지·검사한 응답의 키 원문 부재.
- 로컬 보안 검사: AI OFF, 외부 Host/forwarded Host 403, `.env.local`/Git/서버 소스 404, CSRF·세션 확인. 리스너 주소 `127.0.0.1:3000`.
- TypeScript/ESLint 검사와 `npm run build -- --webpack`. 기본 Turbopack CSS 자식 프로세스 문제는 기존 PC 환경 제한으로 운영 문서에 남겼다.

## 실제 브라우저 확인

- 검정/흰색 줄무늬 반팔, 가슴의 동아리명, 등판의 별도 동아리명·등번호가 함께 표시된다.
- 가슴 가로 7cm와 등판 문구를 독립적으로 수정하고 디자인 저장 성공을 확인했다.
- 개인정보 없는 FIT 샘플 PNG를 첨부하고 앞가슴·등판에 동일 원본을 배치했다. 기존 등번호 레이어는 유지했다. 서로 다른 배치 가로세로 비율에서도 이미지는 원본 비율을 유지한다.
- 소매 별도 색상 분기를 켜고 줄무늬 몸판과 단색 소매의 3D 렌더링을 확인했다. 콘솔 실행 오류가 없었다.
- 무료 업체 변환 후 고객 UV와 업체 패턴에 모든 배치가 남는 것을 확인했다. 앞뒤 3D·UV·패턴을 포함한 5페이지 PDF를 내려받고 렌더링한 3~5페이지를 확인했다. 실제 이메일 발송은 없다.
- 디자인 화면과 업체 자료 화면을 데스크톱 및 390px 모바일에서 확인했다. 가로 넘침이 없고 모바일에서도 원본/3D/UV/업체 패턴/다운로드가 표시된다.
- UI 캡처: `.taste-skill/ai-connection/editor/`. PDF 렌더 검증 이미지: `.taste-skill/ai-connection/pdf-3.png` 등. 이 경로는 QA 자료이므로 Git에서 제외한다.

## 디자인 검사 해석

기존 `design-taste-frontend` 방향·유리 질감을 유지했다. 실제 브라우저 검사 결과 0 FAIL, 3 WARN. `eyebrow` 예외는 진행 단계의 실제 내비게이션과 접힌 폼의 입력 라벨이 장식 라벨로 분류된 오탐 때문이다. 이를 없애면 기능 설명이 사라진다. `still-page` 예외는 디자인 편집 도구에 랜딩 페이지용 등장 애니메이션을 추가하지 않기 위한 것이다. 유리·배경·기존 컴포넌트 스타일 예외는 기존 방향과 사용자 요청을 유지한다.

경고 판단: 크기 종류가 많은 것은 기존 앱의 폼·도구·제목 위계를 유지한 결과이며 전면 재디자인 범위가 아니다. 12px 보조 문구는 기존 단위/보조 안내 크기이고 주 입력은 더 크게 표시된다. 모바일의 혼합/기울임 경고는 복원된 성북핏 로고의 f 표시다. 로고를 유지한다.

시각 검토: 모델과 대화가 데스크톱에서 두 영역으로 정리되고 모바일에서는 모델이 먼저 표시된다. 상세 조절은 접혀 있어 기존 주 흐름을 가리지 않는다. 줄무늬 위 작은 가슴 문구의 대비와 실물 치수는 고객·업체 검수가 필요하다. 모델은 매끈한 연속 표면의 프로토타입이고 실측 피팅 모델은 아니다.

## 남은 운영 과제

실제 AI 응답 품질·잔액/권한, 다중 업로드 이미지, 임의 의류 형태/소매 인쇄, 기기 간 로그인·자료 복구, 실제 업체 포맷/실제 전송, 보관·삭제 정책·금액 예산은 완료된 기능으로 표시하지 않는다. 2D 대체 화면에서 앞뒤 3D를 모두 캡처할 수 없으면 PDF 내보내기를 막고 UV/패턴 원본 다운로드를 안내한다. 클라우드 저장은 Supabase 사용량에 포함된다.
