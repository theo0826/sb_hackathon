# 한땀

한땀은 단체복을 디자인하고 성북구 제작 업체의 견적을 비교해 제작 요청서까지 준비할 수 있는 서비스입니다.

1. 원하는 단체복을 설명하고 생성된 디자인을 3D로 확인합니다.
2. 수량과 수령 정보 등 필요한 항목만 주문서에 입력합니다.
3. 시연용 업체 3곳의 견적을 비교하고, 선택한 업체의 제작 요청서를 확인하거나 내려받습니다.

시연에서는 주문서 입력을 건너뛸 수 있습니다. 업체와 견적은 시연용 예시이며 실제 발송이나 결제는 이루어지지 않습니다.
