# 성북핏

Next.js 프론트엔드와 Supabase DB·비공개 Storage, 서버 전용 OpenAI API를 연결한 단체복 디자인·견적 요청서 서비스입니다.

**제작 흐름: ① AI 디자인 만들기 → ② 업체 선택 → ③ 주문 조건 입력·AI 업체 맞춤 견적 요청서 생성·서버 저장.** 디자인·도안 저장은 선택 사항이며, 제작 흐름 중 저장을 강제하지 않습니다.

## 지금 확인할 수 있는 것

- `/`: 3D 의류 애니메이션과 스크롤에 따라 겹쳐지는 제작 과정 패널을 표시합니다. 티커·큰 2D 이미지 목록·상단 시작 버튼은 제거했고, 하단 디자인 시작하기로 이동합니다.
- `/design`: 왼쪽의 3D 의류 미리보기와 오른쪽의 대화 입력. 반팔·후드·과잠을 선택하고 로고/이미지를 첨부하거나 지시사항을 입력합니다. 생성한 디자인은 저장하거나 **업체 선택하기**로 이어갈 수 있습니다.
- `/suppliers`: 업체 목록과 지역·제작 방식·제출 양식·소량 제작 필터. 가상 업체 3곳을 비교하고 선택합니다.
- `/editor`: 이전 링크 호환용. 통합된 `/quotes/new` 화면으로 이동합니다.
- `/quotes/new`: 단체 이름·연락 이메일·사이즈별 수량·수령일·제작 방식·인쇄 크기·요청 사항 입력, 업체 조건 검증, 최종 자료 확인과 체험 요청 제출.
- `/quotes/[id]`: 요청 완료·상세 화면. 제출 당시의 디자인과 주문 정보를 보존합니다.
- `/my`: 디자인 및 통합 도안·제작자료의 누적 보관함, 종류별 개수, 검색·정렬·파일 형식 필터, 즐겨찾기, 휴지통·복원·영구 삭제, 견적 요청 내역.
- `/my/[id]`: 저장 당시의 디자인·지시사항·파일·업체 정보 상세, 이름 변경, 다운로드, 저장된 PDF 열기, AI 화면으로 불러와 이어 만들기.
- PNG/JPG/WEBP 이미지 선택과 브라우저 내부 미리보기. 최대 8MB, 가로·세로 최대 8,000px. 체험용 이미지는 최대 800px로 줄여 사용합니다.
- `POST /api/designs/generate`로 실제 OpenAI 도안을 생성·수정합니다. API 키는 서버에서만 사용합니다.
- 새 디자인·AI 도안·견적 요청서는 Supabase에 저장합니다. 이전 IndexedDB 자료는 유지하며 별도로 저장하는 도안·제작자료 파일은 현재 브라우저에 보관합니다.
- 디자인·선택 업체·주문 조건은 열린 탭에서 공유됩니다. `sessionStorage`로 임시 내용을 유지해 같은 탭에서 새로고침해도 계속 편집할 수 있습니다. 장기 보관하려면 **디자인 저장**을 눌러주세요.
- 티셔츠를 포함한 2D 미리보기 PNG 다운로드. 인쇄용 도안 원본이 아닙니다.
- 좁은 화면에서는 카드가 세로로 배치됩니다.

현재 앞·뒷면은 동일 도안의 인쇄 위치를 선택하는 방식입니다. 양면에 서로 다른 도안을 넣는 기능은 이후 추가합니다. 참고 이미지를 선택하면 문구와 인쇄 색상 조절은 비활성화됩니다. 상세 편집에서 예시 스타일을 선택하면 첨부 이미지 대신 예시 도안으로 돌아갑니다.

## AI 대화와 마이페이지 사용하기

1. 의류를 선택하고, 필요하면 로고나 이미지를 첨부합니다.
2. 하단 입력창에 원하는 디자인을 설명합니다. **Enter** 또는 전송 버튼으로 보내고, **Shift+Enter**로 줄바꿈합니다. 한글을 조합 중일 때 Enter는 전송하지 않습니다.
3. ‘도안을 더 작게’, ‘문구는 SEONGBUK CREW.’처럼 이어서 요청하면 현재 디자인을 기준으로 AI가 기존 도안을 기준으로 결과를 변경합니다.
4. **디자인 저장**은 의류·배치·색상 정보를, **도안 저장**은 티셔츠 배경 없는 SVG/PNG 파일을 새 항목으로 보관합니다.
5. 직접 조절하려면 **상세 편집**을 엽니다. 평소에는 편집 슬라이더·색상 입력이 숨겨져 있습니다.
6. 마이페이지에서 여러 버전을 검색·비교하고 불러옵니다. 이후 편집해도 이미 저장한 버전은 변경되지 않습니다.
7. 업체별 도안 화면의 **도안 보관 / 제작자료 보관**으로 SVG/PNG와 PDF/이메일 파일을 별도로 모아둡니다.
8. 삭제는 우선 휴지통으로 이동하며 복원할 수 있습니다. 휴지통의 **영구 삭제**는 확인 후 실제 삭제합니다.

Supabase와 실제 AI 호출 코드를 연결했습니다. 현재 사용자 비용 보호 요청으로 유료 AI 호출은 비활성화되어 있습니다. 실행 전 `.env.local`에 OpenAI 키와 Supabase 서버 비밀 키를 설정하세요. 설정은 [백엔드 운영 문서](docs/BACKEND.md)를 참고하세요.

## 업체별 제출 방식

| 가상 업체 | 제출 방식 | 예시 제작 조건 |
| --- | --- | --- |
| 장위 스튜디오 | 단체복 제작 PDF 도안서 + 도안·미리보기 파일 | 최소 10벌, DTF·실크스크린, 최대 28 × 35cm |
| 월곡 크래프트 | 이메일 제목·본문 + 도안·미리보기 파일 | 최소 20벌, DTF·자수, 최대 12 × 12cm |
| 종암 메이커스 | 단체 주문 PDF 사양서 + 도안·미리보기 파일 | 최소 30벌, 실크스크린·자수, 최대 30 × 35cm |

업체 규칙은 `lib/suppliers.ts`에서 관리합니다. 모두 가상 데이터이며, 실제 업체의 승인된 양식이나 연락처가 아닙니다. 이메일은 `.txt`로 내려받거나 복사하며 실제 발송하지 않습니다. PDF는 한글과 도안을 이미지로 포함하는 A4 제작자료입니다. 첨부 이미지는 최대 800px의 편집용 파일이므로 인쇄용 원본 검수는 별도로 필요합니다.

## Windows에서 실행하기

이 컴퓨터에는 프로젝트 안의 `.tools/`에 Node.js LTS를 준비했습니다. 해당 폴더는 Git에 포함되지 않습니다.

1. VS Code에서 이 `seongbuk-fit` 폴더를 엽니다.
2. 터미널을 열고 아래 명령을 실행합니다.

```powershell
.\run-dev.cmd
```

3. 터미널에 표시되는 Local 주소로 접속합니다. 기본 주소는 `http://localhost:3000`입니다. 포트가 사용 중이면 다른 포트가 표시될 수 있습니다.
4. 메인 화면의 **AI 디자인 시작하기** 버튼을 클릭합니다.
5. `/design`에서 의류 선택·이미지 첨부와 하단 지시사항 전송을 확인합니다.
6. 디자인을 여러 번 바꾸어 **디자인 저장 / 도안 저장**을 누르고, 마이페이지에서 누적 항목과 새로고침 복원을 확인합니다.
7. 하단의 **이 디자인으로 업체 선택**을 누릅니다.
8. 업체 카드에서 **이 업체 선택**, 하단에서 **수량 입력하고 맞춤 도안 보기**를 누릅니다.
9. 주문 조건을 입력하고 **AI 견적 요청서 만들기**를 누릅니다. 선택 업체의 PDF 도안서 또는 이메일 본문과 첨부 도안을 확인합니다.
10. AI 설명과 업체별 양식을 검토한 뒤 **견적 요청서 보관함 보기**로 이동합니다. PDF·이메일 자료와 도안을 내려받을 수 있습니다.
11. 완료 화면에서 **내 요청 내역 보기**로 제출 당시의 도안과 주문 정보를 다시 확인합니다.

서버를 종료하려면 터미널에서 `Ctrl + C`를 누릅니다.

Node.js가 시스템에 설치된 다른 컴퓨터에서는 다음과 같이 실행합니다.

```powershell
npm.cmd ci
npm.cmd run dev
```

`npm.cmd`를 사용하면 Windows PowerShell의 `npm.ps1` 실행 정책 문제를 피할 수 있습니다.

## 검사 및 빌드

Node.js가 설치된 터미널에서:

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run build
```

프로젝트에 준비된 Node.js만 사용할 경우, 위 명령 전에 현재 터미널의 PATH를 설정합니다.

```powershell
$fitNode = (Get-ChildItem -Directory .\.tools -Filter 'node-*-win-x64' | Select-Object -First 1).FullName
$env:PATH = "$fitNode;$env:PATH"
```

## 다음 개발 순서

1. 기존 팀 GitHub 저장소 확인 또는 새 저장소 연결, 협업 규칙 합의.
2. 메인·디자인 화면을 팀 디자인 기준에 맞춰 검수.
3. 실제 업체별 양식·인쇄 규격·연락 방식을 확인하고 Mock 규칙 교체.
4. 백엔드 담당자와 [현재 API 계약](docs/API.md), 오류 응답·디자인 저장 구조 합의.
5. Supabase Auth 로그인·기기 간 동기화, 업체 발송·견적 회신 연동. DB·Storage·AI 생성·요청서 저장은 구현 완료.
6. 통합 테스트 후 Vercel에 배포.
7. 2D 편집 흐름이 완성된 후 3D 미리보기 추가.

Supabase와 OpenAI 서버 호출 코드를 연결했습니다. `OPENAI_ENABLED=false`로 유료 AI 호출은 꺼져 있습니다. 실제 업체 발송·견적 회신·배포는 별도이며, 현재 업체 양식은 가상 데이터 기반 초안입니다. 계정 로그인 없이 브라우저 세션으로 자료 접근을 제한하므로 다른 기기에서 보려면 추후 Auth 로그인 연동이 필요합니다.

기술 문서: [Next.js 설치](https://nextjs.org/docs/app/getting-started/installation), [Node.js 공식 다운로드](https://nodejs.org/en/download).

- 완료·내역의 새로고침 복원, 이후 디자인 편집과 제출 당시 디자인의 분리 확인.
- 업체·맞춤 자료·견적 입력·최종 자료·완료·요청 내역의 390px 모바일 가로 넘침 없음.
- 단일 저장의 한 번 이전, 여러 디자인·도안·PDF·이메일의 누적 저장과 새로고침 복원 확인.
- 보관함 검색·정렬·형식 필터, 이름 변경·즐겨찾기·휴지통 복원·파일 다운로드 확인.
- AI 입력창의 하단 배치, 기본 상세 입력 숨김, 추가 요청의 현재 디자인 반영과 대화 복원 확인.
- 한글 조합 중 Enter 전송 방지, 일반 Enter 전송, 누적 보관함 저장 실패·재시도와 휴지통의 선택 항목 영구 삭제 확인.

### 3단계 제작 흐름 검증

별도 테스트 브라우저에서 디자인·도안 누적 저장, 업체 단일 선택, PDF·이메일 맞춤 도안의 주문 정보 반영 및 파일 보관, 주문 수정 시 입력 유지, 체험 요청 완료, 기존 `/editor` 링크 호환, 디자인 없는 직접 진입 안내, 모바일 레이아웃을 확인했습니다.

### 도안·제작자료 통합

마이페이지의 내 도안과 업체별 제작자료 메뉴를 도안·제작자료로 통합했습니다. 원본 SVG/PNG와 업체 PDF/이메일은 형식 필터로 구분합니다. 기존 자료는 삭제하거나 변환하지 않고 같은 메뉴에서 표시합니다. 새 업체용 보관은 제출 양식, 원본 도안, 의류 미리보기를 한 항목에 저장하며 상세 화면에서 각 첨부 파일을 내려받을 수 있습니다. 디자인 화면에서 저장하는 업체 미선택 원본 도안도 이 메뉴에 표시합니다.


## 백엔드 설정과 검증

업체 도안 목업 3종은 `/patterns`에서 확인할 수 있습니다. 고객 확인용 UV와 업체 봉제·인쇄 패턴을 별도 자료로 두고, AI 또는 비용 없는 목업 변환으로 해당 업체 양식에 맞춘 뒤 역검증·저장·SVG/JSON/PDF/이메일 출력까지 연결했습니다. 상세 내용은 [UV·패턴 변환 프로세스](docs/UV-PATTERN-CONVERSION.md), 양식 예시는 [목업 파일 3종](docs/pattern-mockups/README.md)에 있습니다.

새 기능과 보안 구성, 키 입력 방법은 [백엔드 운영 문서](docs/BACKEND.md), 서버 계약은 [API 문서](docs/API.md)에 정리했습니다. Node.js 22 이상을 사용합니다. `tests/backend-api.mjs`는 세션·소유권·비공개 파일·샘플 업체 3종 요청서·키 노출을 검사합니다. `tests/ai-contract.mjs`는 외부 호출 없는 AI 모듈 테스트입니다. 유료 AI 테스트는 실행하지 않습니다.

### 전체 의상 요청과 백엔드 협업

디자인은 원단·소매·테두리 색과 앞뒤 최대 4개 이미지/문구 배치를 분리합니다. 업로드 원본은 여러 위치에서 재사용하고 정확한 문구와 등번호는 사이트가 그립니다. 무료 테스트에서 유니폼 줄무늬·동아리명·등번호 예제를 확인할 수 있습니다. 실제 프롬프트 해석·생성 품질·DB 운영은 백엔드 팀원이 완성할 프로토타입입니다.

- [백엔드 팀원 인수·협업 가이드](docs/BACKEND-TEAM-HANDOFF.md): 역할, 공유 방법, 실행, 검증, 남은 운영 과제.
- [AI API 데이터 계약](docs/AI-API-CONTRACT.md): 디자인·배치·원단 JSON, 서버 응답, 업체 변환 규칙.

- 유료 AI는 계속 OFF입니다. 키/잔액/모델 권한과 실제 품질은 별도 검증해야 합니다. 실제 업체 발송과 실측 봉제 패턴은 아직 없습니다.
