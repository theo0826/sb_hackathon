# 성북핏 taste skill 디자인 적용 기록

적용 스킬: design-taste-frontend v2(메인 페이지), redesign-existing-projects(편집·업체·마이페이지).
기술 구성은 Next.js / TypeScript / React Konva를 유지했습니다.

## 방향과 성북핏의 소재

선택 방향: The split stage. Seed: 897981253. 팔레트·글꼴은 기존 브랜드 기준을 유지했으며 다시 추첨한 항목은 없습니다.
소재 목록: 성북이라는 지역, 대학 동아리 반티, 반팔·후드·과잠, 팀 문구, 캠퍼스 배지, 크루 웨이브, AI 지시사항, 앞·뒷면 배치, 이웃 제작 업체, 업체별 PDF·이메일, 원본 도안과 미리보기, 누적 보관함.
아이디어: 성북핏에서 만든 팀 의류를 고정된 미리보기 무대로 보여주고, 대학의 아이디어가 업체 전달자료가 되는 과정을 옆에서 설명한다.
사용자가 할 수 있는 일: 예시 의류를 직접 바꾸고 선택한 의류와 지시사항으로 디자인 작업을 시작한다. 기존 장기 보관함은 유지하며 작업 초안만 새 예시로 시작한다.

## 페이지의 주장과 증거

- 대화로 우리 팀의 반티를 만들 수 있다: 큰 의류 예시와 실제 디자인 화면 연결.
- 반팔·후드·과잠에 서로 다른 분위기를 적용할 수 있다: 편집기에서 내보낸 의류별 결과.
- 디자인에서 제작자료까지 이어진다: 디자인, 업체 선택, PDF·이메일 제작자료라는 실제 기능 설명과 링크.
- 바로 시작할 수 있다: 선택 예시를 지시사항 입력창에 전달하는 시작 버튼.

## 이미지와 동작

public/previews/campus.webp, wave.webp, club.webp, print.webp는 현재 프로젝트의 2D 편집기에서 1040px로 내보낸 실제 예시 화면입니다. 외부 사진·모델 이미지·가짜 제작 사례를 사용하지 않았습니다. 상업용 실물 사진으로 소개하지 않으며 예시 디자인임을 페이지에 표시합니다.
실제 성북 의류 제작 영상은 공개 자료 검색에서 적합한 결과가 없어 사용하지 않았습니다. 영상 부재 경고 1개는 이 이유로 유지합니다. 자동 교차 전환과 실제 예시 선택으로 의류를 보여줍니다. 동작 줄이기에서는 전환과 등장 애니메이션을 끕니다. 스크립트가 없을 때도 본문과 링크는 보입니다.

## 화면 비평 및 수정

변경 전: 작은 라벨·번호·아이콘 카드, 다수의 음영과 그라데이션, 부족한 이미지 면적이 화면의 우선순위를 흐렸습니다. 검사에서 실패 13개가 나왔습니다.
첫 수정: 큰 의류 무대와 읽는 영역으로 분리하고 실제 예시 4종을 마련했습니다. 글자 크기 수를 줄이고 대비를 높였습니다.
후속 수정: 등장 애니메이션을 실제 스크롤 진입에 맞추고, 헤더 글자 크기를 정리했습니다. 메인 이미지는 저해상도 캔버스 캡처 대신 원본 다운로드로 교체했습니다.
최종 자체 평가(10점 만점): 디자인 8, 사용성 8, 창의성 7, 내용 8. 가중 점수 7.8. 실물 의류·제작 현장 사진이 없어 브랜드의 현장감은 아직 제한됩니다. 모델링된 3D 실물 시뮬레이션을 표시하거나 주장하지 않습니다.
