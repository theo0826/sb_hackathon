## 2026-10-29 저장 디자인의 3D 이어 만들기 복원

저장 때 앞면 썸네일만 남기고 불러오기에서 clothData를 지우던 연결을 수정했습니다. 새 저장본은 의류 원본 장면의 metadata·ArrayBuffer, 앞뒤 캡처, 토큰·로고·가격·의류 조건을 IndexedDB에 독립된 보관본으로 저장합니다. 이어 만들기와 저장 후 새로고침은 해당 장면을 실제 ClothSim/WebGPU 엔진에 다시 연결하며, 모듈 장면 캐시와 저장 ID를 사용해 다른 디자인이 섞이지 않도록 합니다. 저장 당시의 로고 편집을 이어 할 수 있고 수정 후 다시 캡처되면 주문서 작성 버튼이 활성화됩니다. 새 주문의 단체·이메일·수령일·추가 요청 및 주문 상세는 다시 입력합니다. 보관함 목록과 상세는 로고 원본 대신 저장한 의류 썸네일을 우선 표시합니다.
