## 2026-10-19 단일 미리보기와 업체 도안 진입점

사용자 확인에 따라 의상 시뮬레이션 탭과 별도 입력·생성 폼을 제거하고, ClothSim 기능은 하나의 디자인 미리보기에 유지했습니다. 왼쪽 공통 입력과 AI 시안 만들기로 의상을 생성하며, 새 디자인 API를 설정한 경우 같은 입력으로 인쇄 시안도 요청합니다. 생성 취소·중복 제출 방지·오류 시 기존 미리보기를 유지하고 개인 키 연결은 차단한 채 둡니다. 업체 비교 화면의 각 카드에 AI 맞춤 도안 만들기를 추가해 선택 업체의 /quotes/prepare로 연결합니다. 데스크톱은 기존 카드 마지막 열에, 모바일은 카드 전체 폭에 배치했습니다. 기존 녹색 글래스 디자인·시연 주문 동선을 유지하고 새 방향은 추첨하지 않았습니다.

사용자 요청으로 AI 시안 생성·업체 양식 변환 버튼의 서버 상태 의존 잠금을 제거했습니다. 기존 녹색 글래스 디자인과 로딩 중 중복 제출 방지는 유지하고 새 디자인 방향을 추첨하지 않았습니다. 새 백엔드의 두 엔드포인트만 lib/ai-client.ts로 연결하며 개인 API·Supabase에는 대체 요청하지 않습니다. 기존 개인 서버는 기본 차단했고 자료 저장은 브라우저로 분리했습니다. API 미설정 시 연결 준비 안내를 표시합니다. 이 기록이 아래의 개인 서버 활성화 관련 이력보다 우선합니다.


## 2026-10-19 ClothSim 생성 기능을 디자인 화면에 통합

origin/main의 PR #1(ce1b1ce, 1d7c707)을 feature/ui에 병합했습니다. 두 홈 파일의 충돌은 기존 홈을 유지해 해결하고, 새 ClothSim 생성기는 디자인 스튜디오의 의상 시뮬레이션 탭으로 연결했습니다. 새 방향 추첨이나 홈 재설계는 하지 않았으며 기존 녹색 글래스 스타일을 유지했습니다.

옷 형태 설명은 인쇄 문구와 별도 입력입니다. 명시적인 생성, 취소, 진행 상태, 연결 실패·WebGPU 미지원 안내를 제공하며 준비 전과 실패 시 기존 디자인 미리보기를 유지합니다. 탭 전환 시 입력과 생성 장면을 유지하고 시뮬레이션 계산을 일시정지합니다. 새 디자인을 시작하거나 페이지를 떠나면 생성 작업과 장면을 정리합니다. 생성 결과는 실험용으로, 기존 반팔 인쇄 도안·저장·주문 자료를 변경하지 않습니다. 생성은 팀원 구현의 Ollama localhost 연결을 사용하며 배포 환경의 공용 생성 서버 연결은 별도 작업입니다.

운영 Webpack 빌드, 정적 Pages 빌드·경로 검사, TypeScript, 기존 단위 테스트 통과. ESLint 오류 0개, 동료의 생성 자산과 훅 의존성 등 기존 경고 65개는 유지했습니다. 새 solver의 예약 변수명과 타입 선언의 any 2곳만 최소 수정했습니다. 실제 Chrome 1440/768/390px에서 생성 장면과 컨트롤을 확인했고 가로 넘침은 없었습니다. LLM 응답을 대체한 테스트에서 실제 WASM 장면 생성과 WebGPU 렌더, 연결 실패·취소를 확인했습니다. 실제 Ollama 모델을 통한 생성 품질은 확인하지 않았습니다.

스킬 소스 lint는 실패·경고 0개입니다. 마케팅용 inspector는 앱의 기존 버튼 음영·윤곽선·작은 보조문구·사진 없는 폼 구성을 지적했으며 이번 병합에서는 기존 디자인과 기능을 유지했습니다. 새 이미지·영상·가상 실적은 추가하지 않았습니다. 화면 기록은 .tools/cloth-*.png, 기본 디자인 inspector는 .taste-skill/inspect-cloth-merge/에 있습니다.

## 2026-10-16 성북구 주민 대상·마이페이지 통합·글래스 스타일

사용자 요청에 따라 제품 문구를 ‘반티’에서 ‘단체티’로 바꾸고 성북구의 모든 주민을 대상으로 소개합니다. 주민 모임·동호회·가족 행사·직원복을 이용 예시로 쓰고, 제목·메타 설명·업로드 안내·주문서 예시·제작 문의 양식·새 디자인 기본 문구까지 맞췄습니다. 내부 스타일 ID와 기존 저장 자료는 호환성을 유지합니다.

상단은 로고와 마이페이지 드롭다운만 남겼습니다. 드롭다운의 디자인·주문·이용 방법은 `/my?tab=design`, `/my?tab=orders`, `/my?tab=guide`로 연결되며 선택 항목은 URL에 유지됩니다. 주문 항목에는 시연 제작 진행과 기존 견적 요청서·제작자료를 함께 보여줍니다. 기존 `/orders`는 통합 주문 화면으로 이동하며, 주문 상세·휴지통·복원·기존 자료 주소는 보존했습니다. Esc·바깥 클릭·메뉴 선택으로 드롭다운이 닫힙니다.

녹색 정체성과 화면 흐름을 유지하면서 반투명 배경·유리 테두리·배경 흐림·겹친 음영을 `app/glass-theme.css`로 적용했습니다. 그림자·유리 질감·배경의 미세한 색 변화는 이번 사용자가 명시적으로 요청한 요소로, taste skill의 기본 금지 규칙보다 우선합니다. 새 방향을 추첨하지 않았습니다. 겹치는 스택 카드 바탕은 이전 카드 글자가 비치지 않도록 불투명하게 두고 테두리·음영과 내부 자료의 유리 질감을 유지합니다. 홈 마지막 시작 버튼은 전체 폭 배너 대신 데스크톱 약 172×47px의 작은 버튼으로 줄였습니다.

실제 1440px·390px에서 홈·스튜디오·마이페이지와 드롭다운을 확인했습니다. 메뉴를 통한 항목 이동, 주문 생성 후 통합 목록과 개수 표시, 새로고침 유지, 기존 주문 주소 이동, 모바일 가로 넘침 없음, 메뉴와 진행 표시가 겹치지 않음을 확인했습니다. TypeScript·ESLint·단위 테스트·Webpack 빌드를 통과했습니다. 렌더는 `.taste-skill/inspect-resident-glass/`에 있습니다.
