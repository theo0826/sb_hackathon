# 로컬 실행·보안·비용 점검

점검일: 2026-10-15 (KST). 이 문서는 현재 코드와 이 컴퓨터에서 확인한 결과입니다.

## 외부 접속과 데이터 이동은 다릅니다

- 개발·프로덕션 실행 스크립트 모두 `--hostname 127.0.0.1`로 제한했습니다.
- 실행 중인 3000 포트가 `127.0.0.1`에만 연결됨을 확인했습니다. 일반 LAN 주소나 인터넷에서 이 서버로 직접 접속할 수 없습니다.
- Host/forwarded Host 검사로 다른 도메인의 요청과 실수로 배포된 인스턴스를 차단합니다. 공개 도메인 Host와 forwarded Host 요청이 실제로 403을 반환했습니다.
- 알려진 ngrok/cloudflared/frpc/localtunnel/SSH 역방향 터널 프로세스와 Windows portproxy 설정을 점검했습니다. 검사 당시 해당 터널은 발견되지 않았습니다. 새로운 터널 설치나 프록시 설정까지 영구적으로 막는 운영체제 보안 기능은 아닙니다.
- 이번 작업에서 사이트를 배포하거나 공개 링크를 만들지 않았습니다. 별도 계정의 모든 과거 배포·공유 설정을 전수 검사한 것은 아닙니다.
- **자료 저장은 로컬 전용이 아닙니다.** 디자인 저장·제작자료 저장을 누르면 이미지, 도안, 주문 정보와 입력한 연락 이메일이 비공개 Supabase 클라우드에 저장됩니다. 프로젝트 URL이 존재한다는 것과 데이터가 공개라는 것은 다릅니다.
- 새 무료 테스트 대화는 규칙 기반으로 브라우저에서 처리합니다. 대화 입력을 서버나 AI로 전송하지 않습니다. 디자인 초안은 이 탭의 sessionStorage에 남습니다. 별도의 저장 버튼을 누르면 위의 클라우드 저장이 적용됩니다.
- Higgsfield에는 개인정보 없는 기본 의류 모델링 코드만 전달했습니다. 비공개 프로젝트에서 만든 모델을 내려받았으며 사이트 실행 중에는 Higgsfield를 호출하지 않습니다.

## 키와 접근 제어

- OpenAI/Supabase 비밀 키는 `.env.local`의 서버 전용 변수이며 `NEXT_PUBLIC_`로 노출하지 않습니다. `.env.local`은 Git 추적 대상이 아니고 HTTP 요청은 404입니다.
- 실제 키 문자열이 브라우저 정적 번들, 페이지 HTML, 검사한 API 응답에 없는 것을 자동 검사했습니다. 키 원문을 로그나 문서에 기록하지 않았습니다.
- Supabase 4개 테이블에 RLS를 적용하고 브라우저 역할의 직접 접근을 차단했습니다. 서버는 각 조회·변경·이미지 다운로드에 소유자 조건을 적용합니다. 다른 세션의 읽기·변경·다운로드가 거부되는 것을 실제 API로 확인했습니다.
- 저장소는 비공개 `fit-private` 버킷입니다. 공개 이미지 URL 대신 세션이 필요한 로컬 API를 사용합니다. Supabase security advisor 결과는 경고 없음입니다.
- 세션은 무작위 256비트 HttpOnly/SameSite 쿠키로 구분합니다. 로그인 계정이 아니므로 같은 브라우저 사용자나 쿠키를 가진 사람은 같은 소유자로 취급됩니다. 쿠키를 지우면 기존 자료에 접근할 수 없습니다.
- CSRF Origin/Fetch-Site 검사, JSON 본문 크기·이미지 해상도 제한, 오류 메시지 정리, no-store 응답을 확인했습니다. EXIF가 없는 PNG로 이미지를 다시 인코딩합니다.
- 프레임 삽입 차단, referrer 전송 차단, 카메라·마이크·위치 권한 차단, 검색 색인 거부, 외부 브라우저 통신을 제한하는 CSP를 추가했습니다. 개발 호환성을 위해 inline script/style 및 eval을 허용하므로 엄격한 nonce 기반 CSP와 같지는 않습니다.
- AI 업체 변환 입력에서 연락 이메일·단체 이름·자유 메모를 제거했습니다. 문서에는 서버의 원본 주문 정보로 채웁니다. 사용자가 그래픽 문구나 이미지에 개인정보를 직접 넣으면 AI 활성화 시 그 내용은 AI 처리 대상으로 전달될 수 있습니다.

## 비용

- 현재 `OPENAI_ENABLED=false`. 실제 `/api/status`와 AI 차단 API 검사로 확인했습니다.
- 무료 대화와 정적 GLB 모델의 회전·색상·도안 변경은 AI API를 사용하지 않습니다. 목업 패턴 변환도 유료 AI 호출과 AI 작업 예약을 하지 않는 별도 경로입니다.
- 이번 검증에서 실제 유료 OpenAI 호출 및 Higgsfield AI 이미지·영상 생성 호출은 실행하지 않았습니다. 결제, 플랜 변경, 토큰 구매, 유료 애드온 활성화도 하지 않았습니다.
- AI를 다시 켜면 OpenAI API 사용료가 발생할 수 있습니다. 기존 요청 수 제한은 기본 전체 하루 30회, 세션 시간당 5회이며, 중복 요청 키와 완료 작업 복구로 동일 요청의 중복 처리를 억제합니다. 전체 의상 확장 후 한 작업은 새 그래픽 1장과 커스텀 원단 1장까지, 최대 이미지 호출 2회입니다. 문구·기본 무늬·기존 이미지 배치는 새 이미지가 필요 없습니다. 각 텍스트 응답 출력 상한은 3,000토큰입니다.
- 요청 횟수 제한은 금액 상한이 아닙니다. OpenAI API 과금은 ChatGPT/Codex 구독 사용량과 별개입니다. 외부 계정에서 별도로 사용한 키의 비용이나 앞으로 변경되는 청구까지 이 코드가 보장하지 않습니다.
- 클라우드 저장·전송·DB 사용량은 Supabase 사용량에 포함됩니다. 현재 플랜의 청구·지출 한도는 대시보드 기준이며, 테스트가 모든 서비스에서 무조건 영구 무료라고 보장하지 않습니다. 로컬 서버나 무료 대화 자체는 OpenAI 토큰을 소모하지 않습니다.
