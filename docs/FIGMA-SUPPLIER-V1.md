## 원본과 범위

Figma 파일 `KwTrTVlcQvTOi9seJSeWFU`에 연결하여 원본 구조·디자인 컨텍스트·스크린샷을 확인했다. 첨부 이미지만 추정해서 구현하지 않았다.

- PC 견적 수신: `420:2`, 빨간 주석 `420:155`
- PC 견적 비교: `398:2`, 빨간 주석 `407:2`
- 모바일 수신/비교: `441:2`, `441:68`, 빨간 주석 `439:156`
- 적용 화면: `/suppliers`. 비교 이후 기존 `/quotes/prepare`에 선택한 업체를 전달한다.

기존 디자인 방향 파일을 유지하고 새로운 방향을 추첨하지 않았다. 원본의 아이콘/로고 15개는 `public/figma/suppliers`에 저장했다. 임시 Figma URL을 런타임에서 호출하지 않는다. Noto Sans KR와 Inter는 공식 Google Fonts 배포본을 WOFF2로 압축해 화면에만 적용한다. 라이선스는 `public/fonts/suppliers`에 둔다.

| 추천 기본 선택 | 조건에 맞는 도착 견적 중 최저가, 동가면 빠른 제작 |

| 우측 패널 | 내 주문 압축 요약, 선택 업체/견적 금액 즉시 갱신, 다음 화면 연결 |
| 모바일 | 단일 열, 지역/최소수량/사이드바 생략, 52px CTA와 safe-area 하단 바 |
| 모바일 CTA | 선택한 업체명 반영, 한국어 조사 `로/으로` 처리 |
| 안내 문구 | 원본의 제작 파일 확인 후 금액 조정 문구, PC에 시연 예시 문구 |
| 저장하기 | 캡처만 저장하지 않고 원본 3D scene·로고·의류 데이터까지 보관 |

현재 시연 업체는 장위 스튜디오(장위동, 최소 10벌, 7–10일), 정릉 어패럴(정릉동, 최소 20벌, 5–7일), 석관 프린팅(석관동, 최소 10벌, 10–14일)이다. 반팔 25벌·DTF 기준 견적은 각각 112,500 / 125,000 / 137,500원이다. 기존 의류별 차액·수량 할인·자수 가산 계산을 공유한다.

제작 기간은 표시 범위의 상한으로 계산하여 희망 수령일까지 제작할 수 없는 업체를 제외한다. 배송 소요일을 별도로 추정하지 않는다. 기존 저장 주문의 업체 ID는 보존하고 새 시연 업체 ID를 추가했다.

새로고침 시 기본 서버 스냅샷으로 저장된 견적을 덮어쓰지 않도록 실제 주문과 캡처가 준비된 뒤 요청 상태를 읽는다. 요청 시간·비교 상태·선택·정렬은 같은 탭에서 유지된다. 캡처만 갱신되었을 때에는 새 요청을 만들지 않는다.

## 검증

- 단위 검사: 정확한 금액, 수량/방식/크기/납기 조건, 정렬과 추천, 요청 식별/복원/초기화, 과거 업체 ID 호환.
- 실제 Chrome: 1440 / 1024 / 768 / 390 / 360px, 진행률과 순차 도착, 자동 전환 없음, 조기 비교, 라디오 선택과 금액, 정렬/새로고침, 수정 취소·확인·재요청, 다음 제작 요청서 연결.
- 석관 프린팅 선택 후 기존 전달 완료 화면과 저장된 주문의 새 업체 ID를 확인했다. 상단 저장 버튼으로 복사한 3D 장면의 SHA-256과 앞면 캡처가 원본과 동일함을 확인했다.
- TypeScript, 변경 코드 ESLint, 전체 단위 검사, Next.js 프로덕션 빌드, 소스 taste lint를 통과했다. 화면 inspector는 문서화한 시안 예외를 제외하면 실패·경고가 없다.
- 사용자 지정 앱 화면이므로 마케팅 사진·영상 기준을 적용하지 않았다. 원본에서 지정한 옅은 보조 문구와 컨트롤 그림자는 시안 요구에 따라 유지했다.
- 기록: `.tools/supplier-v1-*.png`, `.tools/supplier-v1-inspection.json`, `.tools/verify-supplier-v1.mjs`.

실제 업체 견적 수집, 실제 발송, 결제 API는 이번 화면 작업 범위에 포함되지 않는다.
