# 성북핏 디자인팀 와이어프레임 적용

2026-10-16. 제공된 캡처와 공개 프로토타입을 브라우저에서 읽어 기존 Next.js 프로젝트에 적용했습니다. Figma 파일 API 접근이나 새 디자인 추첨은 하지 않았습니다.

추가 요청 적용: 성북구 전체 주민을 대상으로 단체티 용어를 사용합니다. 녹색 기반 글래스 질감·음영을 적용하고 홈의 마지막 버튼을 줄였습니다. 상단의 마이페이지 드롭다운에서 디자인·주문·이용 방법을 열 수 있습니다.

## 화면과 이동

| 주소 | 역할 |
| --- | --- |
| `/` | 성북구 주민 대상 소개, 움직이는 3D 의류, 스크롤 카드, 작은 디자인 시작 버튼 |
| `/design` | 데스크톱 3열 / 모바일 1열 스튜디오, 로고 업로드, AI·무료 예시, 배치 시안, 색상, 3D, 저장 |
| `/quotes/new` | 명단 또는 사이즈별 수량, 납기·수령, 대표자·결제 방식, 앞뒷면 확인 |
| `/suppliers` | 예시 견적 비교, 추천·가격·납기 정렬, 업체 선택 대화상자 |
| `/orders` | `/my?tab=orders`로 이동하는 기존 주소 |
| `/orders/demo_…` | 선택한 주문 스냅샷과 시연 제작 타임라인, 예시 결제 정보, 도안 |
| `/quotes/prepare` | 기존 업체별 PDF·이메일 제작자료 생성·저장 |
| `/my?tab=design` | 저장한 디자인과 새 단체티 디자인 시작 |
| `/my?tab=orders` | 시연 제작 진행 및 기존 견적 요청서·제작자료 |
| `/my?tab=guide` | 주민 모임·동호회·가족 행사·직원복을 위한 이용 방법 |
| `/my?tab=trash`, `/quotes/[id]` | 휴지통·복원과 기존 요청서 상세 |

## 데이터와 실제 연동 범위

- 기존 지원 범위인 단색 반팔·로고 디자인을 유지합니다. 과잠·후드 등 추가 품목은 지원 준비 상태로 표시합니다.
- 기존 가상 업체 3곳을 재사용합니다. 단가·제작 진행·승인·결제는 표시된 시연 데이터이며 실제 업체 응답이 아닙니다.
- 업체 선택 시 결제·발송 없이 주문 스냅샷을 현재 탭의 `sessionStorage`에 보관합니다. 새로고침은 지원하며 다른 탭·기기·브라우저나 닫은 탭의 복구는 보장하지 않습니다. 저장 실패를 성공으로 처리하지 않습니다.
- 명단은 CSV UTF-8와 직접 입력을 지원합니다. 이름·사이즈·선택적 필수 이니셜의 누락을 표시하며 사이즈별 수량을 계산합니다. BOM, 인용과 쉼표가 포함된 이름을 처리하고 파일 1MB·명단 500명으로 제한합니다.
- 명단과 추가 배송·결제 선택은 시연 스냅샷에 포함됩니다. 기존 서버 제작자료 API에 개인별 명단을 보내거나 개인화 인쇄를 추가하지 않았습니다.
- 업체 선택은 기존 최소 수량·제작 방식·인쇄 한도와 실제 배치 크기로 판단합니다. 희망 수령일은 확약된 납기와 구분합니다.
- 확인 후 디자인·명단·주문 조건을 수정하면 확인 체크를 해제합니다.
- AI·디자인 저장·업체 양식 변환은 기존 서버 기능과 비공개 자료 취급을 유지합니다. 검증에서는 유료 AI나 업체 전송을 호출하지 않았습니다.

## 검증

- TypeScript / ESLint 통과.
- `npm run test:unit`: 기존 디자인 계약·54개 생산 매핑·3D 모델·AI mock 및 신규 주문 흐름 테스트 통과.
- 신규 테스트: CSV BOM·인용·최대 인원, 사이즈별 합계, 이름·이니셜 누락, 과거·잘못된 날짜, 주소·확인 누락, 단가·총액 계산.
- `npm run build -- --webpack` 통과. 기본 Turbopack 빌드는 이 Windows 실행 환경에서 컴파일 단계에 머물러 중단했습니다.
- 실제 브라우저: 데스크톱과 390px 모바일의 디자인·주문서·견적·진행 화면, 정렬·선택·명단 편집, 새로고침 유지, 디자인 변경 후 확인 해제.
- 홈 자동 검사 1440/768/390px: 두 줄 제목, 대비, 반응형. 의도된 카드 겹침·헤더 선 예외로 실패 0·경고 4. 사진·영상·모션 개수·글자 크기 수 경고는 기존 3D 소개의 한계로 기록합니다.
