# Figma 원본 재대조

2026-10-30. 이번 검사는 반응형 동작 검사가 아니라 Figma 원본의 좌표·크기·문구·스타일과 실제 렌더의 대조다. 기존 디자인 방향을 유지했다.

## 발견 및 수정

이전 모바일 검수에서 가로 넘침과 기능이 정상이어도 시안과 동일하다는 뜻은 아니었다. 실제 재대조에서는 다음 차이가 남아 있었다.

- 메인 안내가 약 30px 위에 있었고 예시 카드의 높이·간격이 달랐다. 카드 48px, 간격 8px, 입력창 100px와 Figma의 도구 크기를 적용했다.
- 두 번째 예시 문장과 따옴표가 달랐다. 세 문장 모두 Figma 원문으로 교체했다.
- 주문서의 기본 줄 높이가 누적돼 폼이 약 61px 길었다. 모바일 제목/라벨/탭/입력/설명의 줄 높이와 간격을 원본에 맞췄다.
- 수령일 설명이 제작 방식 아래에 있었다. 수령일 필드 안으로 이동하고 개인별 명단 안내와 전환 버튼을 원본에 맞췄다.
- PC 주문서의 폼 폭·높이와 오른쪽 카드 크기가 달랐다. 전체 페이지 스크롤을 사용하는 Figma 배치를 반영했다.
- 앞뒤 빈 실루엣과 온보딩 화살표를 코드로 대체해 쓰고 있었다. Figma 원본 SVG를 정적 파일로 저장해 사용했다.
- 메뉴의 가로 위치, 온보딩의 상속 자간, 합계의 `총` 글자 크기, 라디오·선·그림자를 보정했다.

## 의도적으로 다른 부분

- 온보딩 모바일 영상: Figma의 358×223.75 대신 사용자가 명시한 원본 코드의 4:3을 유지한다. 원본 모션 멈추기 버튼도 유지한다.
- 생성된 의류/수량/날짜/단체명/이메일/금액은 실제 상태에 따라 달라진다. 비교 캡처에는 테스트용 데이터가 들어 있다.
- 저장할 자료가 없는 첫 진입에서는 저장 버튼이 비활성 상태다. Figma의 정적인 활성 예시와 색이 다르다.
- OS 상태표시줄과 날짜 선택기는 실제 브라우저 동작을 사용한다. 날짜 입력·선택 화살표의 OS 고유 렌더까지 이미지로 덮어쓰지는 않았다.
- 글자 가장자리의 래스터화는 Figma 렌더와 Windows Chrome에서 다를 수 있다.
